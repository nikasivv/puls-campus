# Развёртывание ПУЛЬС

## Вариант 1. Linux/VPS с Docker Compose

1. Установить Docker Engine и Compose plugin на сервере. Проверить, что у хостинга есть постоянный диск, выход в интернет и доступ из России без VPN.
2. Скопировать проект, перейти в папку, выполнить `cp .env.example .env`.
3. Сгенерировать секрет: `python3 -c 'import secrets; print(secrets.token_urlsafe(48))'`, вставить в `.env` вместо шаблонного значения.
4. `docker compose up -d --build`.
5. Проверить `curl http://127.0.0.1:8000/login` и `curl http://127.0.0.1:8000/healthz`.
6. Подключить HTTPS: настроить Nginx/Caddy на домене как reverse proxy на `http://127.0.0.1:8000`, установить TLS-сертификат; в `.env` установить `HTTPS_ONLY=1`, затем `docker compose up -d`.
7. Проверить страницу входа, четыре демокнопки, заявки, PDF и изоляцию аккаунтов **с устройства, находящегося в России, без VPN**. Это нужно проверить фактически; разработка не подтверждает сетевую доступность.
8. Убедиться, что приложение работает до **28 ноября 2026 года** и хостинг не переходит в сон. Не удалять Docker volume `campus_data` между обновлениями.

При развёртывании без Docker сервер должен иметь Python, `fonts-dejavu-core` (для кириллического PDF), Gunicorn и постоянный каталог для SQLite. Команда: `gunicorn --workers 1 --threads 4 --bind 0.0.0.0:8000 wsgi:app`.

**Внимание:** публичный `DEMO_MODE=1` нужен для жюри, но позволяет любому посетителю войти под вымышленными деморолями; поэтому не храните здесь настоящую информацию и не воспринимайте эту схему как production-авторизацию. Даже с защитой исходных аккаунтов публичные пользователи могут менять демонстрационные данные. Для реального вуза необходимо отключить демовход и внедрить полноценный SSO и разграничение полномочий.

## Вариант 2. Обычный сервер Python

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-server.txt
export SECRET_KEY='СЛУЧАЙНЫЙ_ДЛИННЫЙ_СЕКРЕТ'
export DATABASE_PATH='/data/campus.db'
export DEMO_MODE=1
export HTTPS_ONLY=1  # только после HTTPS-прокси
gunicorn --workers 1 --threads 4 --bind 127.0.0.1:8000 wsgi:app
```

Если PDF не создаётся, установите кириллический TTF-шрифт (на Debian/Ubuntu: `sudo apt-get install fonts-dejavu-core`) или укажите абсолютный путь системного TTF через `PULS_PDF_FONT`.

## Перед сдачей обязательно

- Проверить адрес из России без VPN, с телефона от 360 px; логины `student1`, `student2`, `dean`, `admin`.
- Скачать настоящий PDF из уже обработанной заявки и убедиться, что это `application/pdf`, а не ссылка-заглушка.
- Проверить, что чужая заявка и документ возвращают HTTP 404, а админ-раздел студенту возвращает 403.
- Дождаться перезапуска контейнера и убедиться, что заявки и файлы остались в SQLite.
- Создать резервную копию БД и записать адрес сайта, логины и пароли в комментарий к конкурсной заявке.
- Приложить исходники/репозиторий и описание работы с ИИ. Видео до 5 минут желательно.
