# Обновление v4.1 → v5

1. Остановите сервер; сохраните копию `campus.db` (или Docker volume).
2. Замените **исходники** новой версии; не стирайте каталог постоянного хранения БД.
3. Установите зависимости из `requirements.txt` и запустите приложение.
4. При старте `init_db()` сохраняет данные и дополняет схему: `bell_slots`, `schedule_overrides`, `account_activations`, `import_batches`, поля чётности, номеров пар и периода оценки.
5. Старые регулярные занятия переводятся на «обе недели», по соответствующему времени назначается номер пары. Для отсутствующих временных интервалов создаётся дополнительный номер.
6. Редактор теперь находится во вкладке «Деканат → Расписание», а не в общей длинной странице. При корректировке только одной чётности общее занятие разделяется, чтобы другая неделя не пропала.
7. Для исходных **только вымышленных** seed-оценок 2026-11 даты меняются на 2026-06 и помечаются как результаты прошлого семестра, поскольку ноябрьский семестр ещё идёт.
8. Проверьте маршрут «справка → PDF», переходы колокольчика, два аккаунта студентов и календарь до публикации.

Новые тестовые учетные записи, созданные по CSV, получают ссылку активации: после подтверждения импорта скачайте CSV немедленно и храните его безопасно; повторно скачать те же токены нельзя. Повторная загрузка файла с теми же логинами будет отклонена.
