# ПУЛЬС v6 · Campus OS

**Цифровой деканат будущего — рабочий код конкурсного прототипа в номинации «Вайб-кодинг».** Python / Flask, SQLite, HTML / CSS / немного JS. **Неофициальный сервис; только вымышленные данные и аккаунты.** Настоящие сведения о студентах и документы в прототип загружать нельзя.
[Открыть ПУЛЬС — работающий сайт](https://nikasivv-puls-campus-bb7d.twc1.net/)

## Особенность проекта

**Маршрут решения** превращает заявку в законченный процесс: обращение → работа деканата → при необходимости уточнение → выданный PDF или письменный ответ → уведомление студента. Нельзя пометить документ готовым, не предоставив результат. На главной **«Твой ход»** показывает то, что реально требует действия.

**Календарь без догадок**: занятия привязаны к реальным датам, показывают чётность ISO-недели и раскрываются для просмотра информации. Расписание составляется на уровне группы: общие номера пар и время, шаблоны чётной/нечётной/обеих недель, копирование одной недели на обе, разовые изменения на выбранную дату с уведомлениями. Деталь «Аудитория» больше не похожа на ссылку.

**Полноценная информация о занятии (v6):** карточка пары показывает обозначение ЛК/ПР/ЛБ/СЕМ/КОНС/ЗАЧ/ЭКЗ, номер, время, дисциплину, аудитории и преподавателей. По нажатию открывается боковая панель с типом, точной датой, полным списком групп, аудиторий и преподавателей. Деканат может назначить одну пару сразу нескольким группам, указать нескольких преподавателей и аудитории, а также изменить занятие только на одну дату. Данные групп связаны в базе, это не статические подписи. Для новых демоданных подготовлена общая лекция «Системы искусственного интеллекта и большие данные» (три учебные группы, два преподавателя, две аудитории). Старые расписания не изменяются автоматически.

**Зачисление без открытой регистрации**: администратор загружает CSV со списком **вымышленных** зачисленных, система проверяет группы и логины, показывает предпросмотр, после ручного подтверждения создаёт неактивные аккаунты и разово выдаёт CSV с индивидуальными ссылками активации (7 дней). Студент выбирает свой пароль. Дополнительно существует ручное создание аккаунтов с временным паролем для исключений.

## Запуск

Требуется Python 3.10+ (рекомендуем 3.12). Запускайте **из каталога `puls_campus`**.

Windows PowerShell:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Открыть `http://127.0.0.1:5000/login`. При первом запуске создаётся локальная SQLite-база `campus.db`. Все исходные демонстрационные учётные записи доступны по кнопкам быстрого входа:

| Роль | Логин | Пароль при ручном входе |
|---|---|---|
| Студент Александра | `student1` | `1234` |
| Студент Марк | `student2` | `1234` |
| Деканат | `dean` | `1234` |
| Администратор | `admin` | `1234` |

**Демо-вход и пароль `1234` допустимы только с вымышленными данными.** В рабочем вузе требуются вузовский SSO, ограничение полномочий сотрудников, привязка к реестру, аудит и защита от перебора паролей. Режим быстрого входа выключается `DEMO_MODE=0`.

## Рабочие зоны

**Студент:** обзор, недельный календарь с реальными датами, кликабельные карточки занятий и полные подробности с типом, группами, аудиториями и преподавателями, оценки с разбивкой «текущий семестр / архив», заявка и история её обработки, получение PDF или ответа, колокольчик с непрочитанными уведомлениями, профиль и пароль.

**Деканат:** создание и редактирование общего занятия для нескольких групп, выбор типа пары, нескольких преподавателей и аудиторий. Отдельные вкладки «Заявки», «Расписание», «Успеваемость», «Объявления». В расписании: фильтр группы → сетка звонков → нечётный/чётный шаблон с выбором номера пары → изменение или удаление регулярной пары → копирование на обе недели → разовая замена/отмена/дополнение по выбранной дате. Изменения видны студентам группы, и им приходят уведомления. Для выдачи справки — PDF, для иного вопроса — содержательный ответ. Оценки всегда содержат тип контроля и учебный период.

**Администратор:** группы и их параметры, ручное создание/блокировка аккаунтов, роли, пароли, журнал действий, предварительная проверка и подтверждение CSV-реестра с выдачей одноразовых приглашений. Пример — `static/enrollment_example.csv`; поля `username,full_name,group_name` или `Логин;ФИО;Группа`.

## Проверки

```bash
python -m unittest discover -s tests -v
python -m compileall -q app.py schedule_engine.py import_helpers.py tests
```

Отдельно от Flask запускаются 15 тестов календаря, списка преподавателей и аудиторий, общих занятий и CSV:

```bash
python -m unittest tests.test_calendar_pure tests.test_session_metadata -v
```

**Что проверено в среде подготовки v5:** синтаксис Python, парсинг шаблонов, 9 независимых тестов, работа доменной логики с реальной SQLite (включая создание CSV-приглашений и активацию), миграция базы v4 → v5 и предварительный рендер 7 страниц в Chromium на 360/1280 px без горизонтального переполнения. **Что не проверено:** реальные HTTP-интеграционные тесты Flask и запущенный сайт. Flask невозможно было скачать в тестовой среде из-за недоступной сети. Не утверждаем, что прототип уже развёрнут или протестирован в реальном браузере с сервером. См. `QA.md`.

## Переход с v4.1

1. **Сделайте резервную копию `campus.db`**, если вы уже пользовались сайтом. Если база находится в отдельном volume, сохраняйте тот volume.
2. Распакуйте v5 поверх исходного кода (не перезаписывайте рабочую БД архивом).
3. Запустите `python app.py` или `wsgi.py` на сервере. `init_db()` автоматически добавит новые таблицы и поля, настроит номера звонков и сохранит текущих пользователей, заявки, документы, оценки и расписание группы.
4. В **демоданных** исходные результаты осеннего ноября 2026 (которые были некорректно названы итоговыми до конца семестра) помечаются как архив весны 2025/26 с июньскими датами. Настоящие данные никогда не подменяйте таким способом.
5. После обновления браузера используйте `Ctrl + F5`.

Если расписание уже менялось в v4, v5 по умолчанию переносит все регулярные занятия в режим «обе недели». Затем деканат может отредактировать чётную/нечётную отдельно или добавить точечный перенос.

## Для публикации и конкурса

Публикация **обязательна** по ТЗ: публичная ссылка должна работать из РФ без VPN до 28 ноября 2026 г. В архиве подготовлены `Dockerfile`, `compose.yaml`, `wsgi.py`, `DEPLOY.md`. Для сервера установите случайный `SECRET_KEY`, постоянное хранение SQLite, HTTPS и проверьте доступность внешне. **GitHub хранит код, но сам Flask по GitHub-ссылке не запустится.**

Материалы: `QA.md` (проверки), `DEMO_SCRIPT.md` (план выступления), `CRITERIA.md` (сверка с ТЗ), `PROCESS.md` (этапы и решения), `design_previews/` (статические предварительные рендеры, не скриншоты живого сервера).
