# ПУЛЬС v6.5 — навигация администратора

Три пункта **Загрузка**, **Пользователи**, **Журнал действий** перенесены из верхней части страницы в левую навигацию. Общий пункт «Администрирование» убран.

- На широком экране это отдельные пункты бокового меню с выделением выбранного раздела.
- На телефоне три пункта доступны в нижнем меню; «Профиль» остаётся четвёртым пунктом.
- `?tab=import`, `?tab=users`, `?tab=journal` сохранены — старые прямые ссылки работают.
- Содержимое каждого раздела, обработчики форм, роли и сохранение SQLite не менялись.
- Не использовать реальные персональные данные в конкурсном демо.

Для обновления: сделайте резервную копию `campus.db`, замените файлы приложения, не удаляя базу, перезапустите сервер и выполните жёсткое обновление страницы (Ctrl+F5).
