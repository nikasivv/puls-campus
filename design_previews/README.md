# Статические предпросмотры ПУЛЬС v5

Изображения созданы на основе HTML-шаблонов и CSS v5 и срендерены Chromium при ширине 360/1280 px. Это **не скриншоты работающего Flask-сервера**. Для конкурсного отчёта добавьте собственные скриншоты живого приложения.

Включены недельный календарь студента, графический редактор расписания деканата, успеваемость с периодами, рабочие области и мобильные экраны.

## v6 · подробные занятия

- `v6_calendar_1280.png` и `v6_calendar_360.png` — предпросмотр карточек с типами занятий.
- `v6_details_1280.png` и `v6_details_360.png` — открытая подробная карточка общей лекции (3 группы, 2 аудитории, 2 преподавателя).
- `v6_editor_1280.png` — фрагмент редактора деканата с полями типа и множественного состава занятия.

Предпросмотры собраны из текущих HTML/CSS/JS с вымышленными данными; это не скриншоты запущенного Flask-сервера. Старые изображения в этой папке показывают историю дизайна v5 и не обязательно отражают новый состав карточек.
